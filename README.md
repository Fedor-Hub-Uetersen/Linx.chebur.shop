# L# Linx.chebur.shop 🌿

Современный интернет-магазин и информационный портал системы непрерывного мониторинга уровня глюкозы **Linx (Aidex)**, а также сопутствующих аксессуаров и технологий экстренной связи.

## 🚀 Особенности проекта
* **Каталог продукции:** Сенсоры Linx, защитные водостойкие пластыри и индивидуальные QR-профили.
* **Мультиязычность:** Поддержка трех языков интерфейса (**RU / UA / EN**) с мгновенным переключением.
* **Интерактивный слайдер:** Удобный баннер-презентация ключевых товаров в шапке сайта.
* **Быстрый заказ:** Прямая интеграция с мессенджером WhatsApp для моментального оформления заявок.
* **Информация об оплате:** Встроенные реквизиты для банковских переводов (SEPA).
* **Медиаконтент:** Интегрированный видеообзор системы и адаптивный дизайн для любых устройств.

## 🛠 Технологии
* **HTML5 / CSS3 / JavaScript (Vanilla)** — чистый, легкий и быстрый код без тяжелых фреймворков.
* **GitHub Pages** — быстрый и надежный хостинг для развертывания.

## 📂 Структура файлов проекта
* `index.html` — главная страница сайта (содержит всю логику, стили и скрипты).
